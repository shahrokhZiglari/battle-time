⚔ نبرد قلعه‌ها

این فایل، نسخهٔ سورسِ توسعه است و برای اجرای مستقیم (دابل‌کلیک) ساخته نشده؛ به یک سرور توسعه نیاز دارد.

برای اجرای کاملاً آفلاین و بدون نیاز به نصب چیزی:
فایل dist/index.html را مستقیم در مرورگر باز کنید.

برای توسعه یا ساخت دوبارهٔ آن از خط فرمان:

npm install
npm run dev  (حالت توسعه)
npm run build  (ساخت dist/index.html)
