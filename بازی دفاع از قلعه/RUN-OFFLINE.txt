نبرد قلعه ها - راهنمای اجرای آفلاین
==================================

برای اجرای بازی فقط این فایل را با مرورگر باز کنید:

START-GAME-OFFLINE.html

این فایل مستقل است و به اینترنت، نصب Node.js یا اجرای سرور نیاز ندارد.
پیشنهاد: آن را با نسخه جدید Chrome، Edge یا Firefox باز کنید.

فایل index.html موجود در ریشه پروژه، ورودی سورس Vite است و برای اجرای مستقیم نیست.

اگر می خواهید پروژه را دوباره بسازید:

1. npm install
2. npm run build

بعد از ساخت، سه خروجی آفلاین آماده می شود:

- START-GAME-OFFLINE.html
- dist/index.html
- dist/castle-game-offline.html
